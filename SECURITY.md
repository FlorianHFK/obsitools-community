# Sécurité et divulgation responsable

**Ne publiez pas de vulnérabilité exploitable dans une Issue publique.** N'envoyez jamais de mot de passe, de jeton, de dump mémoire, de licence ou de données personnelles dans une discussion.

Pour signaler un risque : **dev@obsitools.com** — objet « OBSITOOLS — Security report ». Décrivez les circonstances de manière minimale, la surface concernée et une méthode de reproduction non destructrice, si possible.

Cette présentation **ne constitue pas un programme de bug bounty** et ne promet ni récompense ni délai contractuel de traitement.

Toute analyse doit se faire sur des systèmes dont vous êtes propriétaire ou pour lesquels vous disposez d'une autorisation explicite.
