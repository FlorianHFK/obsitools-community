## BILL — intelligence rooted in the product

<p align="center"><img src="media/bill-cognitive-flow.svg" alt="BILL: understand, reason, propose, act after approval, verify" width="960"></p>

BILL is designed as **more than a chatbot wrapping cloud APIs**. Its architecture prioritizes native Windows context and local capabilities, with optional local or remote models when they add value.

The doctrine: **understand first → answer when possible → propose when useful → act only on request or approval → verify the outcome**.

**ORBYSS** is part of OBSITOOLS' historical cognitive heritage. **BILL is the active public identity of the sovereign brain.** Integration, testing and proof of capabilities remain ongoing work.

## Specialized worlds, one platform

| Workspace | Purpose |
|:--|:--|
| **WINDOWS CONTROL** | Explore performance, processes, services and faults; propose controlled fixes |
| **AUDIO-STUDIO / COSMOS** | Music creation, DSP processing, audio analysis, sequencing and production workflows |
| **ATLAS** | Discover tools, workspaces, paths and capabilities without getting lost |
| **AI-LAB** | Experiment with local models, providers, agents and tools under human control |
| **CREATIVE / NEURONE LAB** | Creativity, experiments, ideas and exploratory workflows |
| **FORGE / TOOLS** | Windows engineering, automation and supervised experimentation |

**Two complementary interfaces, not duplicates:** the **Ultimate_V2 / Web Premium** experience and the technical **Full Python / Tkinter Powerhouse** track. Both share BILL.
